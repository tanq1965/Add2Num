# Project Add 2 Numbers

## 1. Giới thiệu
Dự án cài đặt thuật toán cộng hai số lớn với logic tính toán mô phỏng theo phương pháp của học sinh tiểu học.

- **Ngôn ngữ & Môi trường:** Java 17, Apache Maven.
- **Thư viện kiểm thử:** JUnit 5.
- **Phiên bản:** 0.0.1.

## 2. Hướng dẫn Cài đặt
Mở Terminal / Command Prompt và chạy lệnh sau để lấy mã nguồn về máy:

    git clone https://github.com/tanq1965/Add2Num.git
    cd Add2Num
    git checkout core

## 3. Hướng dẫn Build & Test

Tại thư mục gốc của dự án (nơi chứa file pom.xml), chạy lệnh sau:

    mvn test
